# 체온 저장 시스템 개발

## 프로젝트 기간

- **2022.03 ~ 2022.04**

## 프로젝트 개요

체온을 기록하고 관리하는 시스템으로, 체온 저장, 날짜 변경 및 체온 삭제, 이름 추가/삭제 기능을 구현한 프로젝트입니다. 이 시스템은 **Tkinter**를 사용하여 **GUI**를 구성하고, **Excel 파일**을 처리하여 체온 데이터를 저장합니다. **Win32com**을 사용하여 Excel 파일을 다루며, 사용자의 요구에 맞는 기능을 자동화하여 업무 효율을 향상시켰습니다.

## 기술 스택

- **Python**
- **Tkinter** (GUI)
- **Win32com** (Excel 파일 처리)
- **PyInstaller** (실행 파일 생성)

## 주요 기능

### 체온 저장 기능
사용자의 이름과 날짜 정보를 기반으로 체온 데이터를 Excel 파일에 자동으로 저장하는 기능을 구현했습니다. 한 명당 최대 3개의 체온 기록을 관리하며, 날짜와 체온을 정확하게 매칭하여 저장합니다.

### 날짜 변경 및 체온 삭제
체온 기록을 삭제하고, 특정 날짜 범위에 대한 체온 데이터를 수정할 수 있는 기능을 구현했습니다. 사용자는 날짜 범위에 맞게 데이터를 업데이트하거나 삭제할 수 있습니다.

### 이름 추가/삭제 기능
사용자가 추가하거나 삭제할 수 있도록 이름 관리 기능을 구현했습니다. 이름은 알파벳 순으로 정렬되어 관리되며, 삭제 시 잘못 입력된 이름도 처리할 수 있도록 예외 처리를 추가했습니다.

### PyInstaller를 활용한 실행파일 생성
Python으로 작성된 코드를 **PyInstaller**를 사용해 실행파일로 변환하여, 독립적인 실행 환경에서도 손쉽게 시스템을 실행할 수 있도록 했습니다. 이를 통해 배포와 실행이 용이하게 되었고, 사용자 편의성을 높였습니다.

### 배운 점
- **UI/UX 디자인**: 사용자 경험을 고려한 직관적인 UI를 설계하는 데 있어 중요한 점들을 배웠습니다. 특히, 체온 데이터 관리와 같은 중요한 기능을 사용자가 쉽게 사용할 수 있도록 만드는 것이 얼마나 중요한지 실감하게 되었습니다.

- **오류 처리**: 예외 처리를 통해 예상치 못한 오류에 대한 대응 능력을 키웠습니다. 특히, Excel 파일을 다루는 과정에서 발생할 수 있는 다양한 오류를 처리하는 법을 배웠습니다.
